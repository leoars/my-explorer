## PDFio 1.6.6

The application includes PDFio by Michael R Sweet, copyright 2021–2026, and its TTF support, copyright 2018–2026. Both are licensed under Apache-2.0. The upstream source revision is fb05e16bb2ae8cf1b1101669b236401dcb36c906. The bundled sources disable diagnostic tracing in debug builds. My Explorer uses its page-copying API to preserve embedded font maps in searchable PDFs. [PDFio upstream](https://github.com/michaelrsweet/pdfio/tree/v1.6.6)

## cmark-gfm 0.29.0.gfm.14

The preview pane reads Markdown files with cmark-gfm, GitHub's fork of the CommonMark reference parser, with its GitHub Flavored Markdown extensions. The sources are vendored unmodified from release 0.29.0.gfm.14, upstream commit 7fe8904ee31fa24b772ae565c4908b1394850de6; four files that CMake generates upstream are written by hand. See Sources/CMarkGFM/README.md for provenance. [cmark-gfm upstream](https://github.com/github/cmark-gfm/tree/0.29.0.gfm.14)
